# Project Notice

This repository is an **independent interoperability project** for the Life Fitness / Indoor Cycling Group (ICG) IC6 indoor bike.

It is not affiliated with, authorized by, sponsored by, or endorsed by Life Fitness or Indoor Cycling Group (ICG). Product and company names are used only to identify compatible hardware. All trademarks belong to their respective owners.

## What this repository contains

The repository contains independently written documentation and example code describing connector wiring, I²C communication, packet structure, checksums, telemetry, calibration reads, and custom-controller examples for tested IC6 hardware.

Where numerical compatibility data is included, it is identified as such. Some coefficients were transcribed as data during interoperability analysis of the user's own IC6 console so independently written software can reproduce the observed device behavior; they are not presented as manufacturer source code.

## What this repository does not contain

This repository does not distribute manufacturer firmware, manufacturer source code, update packages, credentials, or proprietary user-interface artwork.

## Hardware scope

The documented behavior is based on the hardware and software revision tested by this project. Other revisions may differ. Verify connector pinout, signal levels, power behavior, and bus behavior on your own hardware before connecting a controller or issuing write commands.
